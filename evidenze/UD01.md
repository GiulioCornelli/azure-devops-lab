# Evidenza — Preparazione dell'ambiente e metodo di lavoro

## Ambiente verificato

La postazione è un PC personale con Debian GNU/Linux 13 (trixie) installato direttamente, senza WSL. I progetti sono conservati nel filesystem Linux e vengono aperti con Visual Studio Code.

| Azure CLI | 2.74.0 | `az version`; login eseguito con `az login --use-device-code` e `az account show` verificato (identificativi rimossi perché riservati) |

## Workflow completato

Ho ottenuto i materiali clonando il repository pubblico del corso nella cartella di lavoro e aggiornandolo con `git pull --ff-only`. Ho poi creato il repository personale `azure-devops-lab`, l'ho clonato in locale e vi ho copiato il `.gitignore` e il modello dell'evidenza. Per pubblicare questo documento ho usato `git status` per vedere quali file erano modificati o non tracciati, `git add` per portare nello staging soltanto i file richiesti, `git commit` per registrare la modifica in un commit locale con un messaggio descrittivo e `git push` per inviare il commit al repository remoto su GitHub. Prima del commit ho controllato il contenuto con `git diff --cached` e l'assenza di dati sensibili.
